# Стенд измерений распознавания

Данные: `data/utterances/` (последние фразы Мака, `debug.keep_utterances`) и `data/triggers/` (все срабатывания кодового слова с оценками детекторов, `debug.keep_triggers`). Обе папки вне git.

- `giga_texts.py` расшифровывает фразы GigaAM (запускать окружением `helpers/gigaam`), результат в `giga_texts.json`.
- `wake_eval.py` сравнивает детекторы: грамматика (как было), грамматика с «ловушками», полный Vosk, проверка GigaAM и их комбинации. Метки приблизительные: «Боб» считается сказанным, если Whisper его записал.

Результат 2026-11-18 на 58 фразах (27 с кодовым словом, 31 без): грамматика находила 27/27, но срабатывала зря в 13 из 31 (41%); принятая схема «сильное срабатывание сразу, слабое только после проверки GigaAM» находит 24/27 (88%) при 4/31 (12%) ложных. Выборка маленькая (один голос, без шума и музыки), поэтому цифры предварительные.
