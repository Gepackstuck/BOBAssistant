# GigaAM-помощник

Отдельный процесс с собственным окружением (torch, transformers 4.57.1): записывает речь русскими буквами по звучанию, в том числе английские имена («мэдкид вилиан», «вол лотос вэг»). Сервер Боба запускает его сам, если окружение установлено, и пользуется им только когда обычный поиск музыки не нашёл исполнителя.

Установка: `./setup.sh` (несколько минут, скачивает около 2 ГБ). Модель: `ai-sage/GigaAM-v3`, ревизия `rnnt`, код модели исполняется из репозитория на Hugging Face (`trust_remote_code`), я прочитал его перед включением: сеть и запуск процессов он не использует, кроме вспомогательных функций скачивания примеров, которые мы не вызываем.
Протокол: строка JSON `{"wav": "путь"}` на stdin, ответ `{"text": "..."}` на stdout.
