# server — «мозг» Боба на Маке

Слушает микрофон, ловит кодовое слово, распознаёт речь, отвечает через LLM с инструментами
и говорит голосом.

## Установка

Нужны [uv](https://docs.astral.sh/uv/) и [Ollama](https://ollama.com) с моделью:

```sh
ollama pull qwen3:30b-instruct
cd server
uv sync
```

Модели (Vosk около 45 МБ, Silero около 40 МБ, whisper около 1.6 ГБ) скачиваются при первом запуске
в `server/models/` и в кэш Hugging Face.

Своё место для погоды пропишите в `server/config.local.yaml` (в git он не попадает):

```yaml
place:
  name: Москва
  latitude: 55.75
  longitude: 37.62
```

## Запуск

| Команда | Что делает |
|---|---|
| `uv run bob` | Слушает микрофон: «Боб, какая погода?» |
| `uv run bob ask "какая погода?"` | Вопрос текстом, ответ текстом |
| `uv run bob ask "какая погода?" --say` | То же, но с ответом голосом |
| `uv run bob say "Привет"` | Только произнести текст |

В консоль пишется, какие инструменты вызывались и сколько занял каждый шаг:
`⏱ речь→текст 0.34 с | модель 1.20 с | синтез 0.60 с | итого 2.14 с`.

Чтобы модель не выгружалась из памяти через 5 минут простоя, перед запуском Ollama задайте
`launchctl setenv OLLAMA_KEEP_ALIVE -1`.

## Как устроено

```
микрофон 16 кГц → Vosk (грамматика из кодовых слов) → сработало?
  → запись с предзаписью 3 с до тишины 0.7 с (silero-vad)
  → whisper (MLX) → в тексте есть кодовое слово? нет → ложное срабатывание, молчим
  → команда после кодового слова → быстрые шаблоны (время, «стоп») или LLM с инструментами
  → Silero TTS → динамики (микрофон на это время выключен)
```

- **Кодовые слова** задаются в `config.yaml` → `wake`. Vosk отвечает быстро, но ошибается.
  Каждое срабатывание проверяется по тексту whisper (`bob/wake.py`, `WAKE_RE`).
  Позже Vosk заменят обученные модели openWakeWord.
- **Если сказать только кодовое слово**, прозвучит сигнал, и Боб будет ждать команду ещё 5 с.
- **LLM** подключается через адаптер (`bob/llm/`):
  - `openai_compat`: Ollama, LM Studio, любой OpenAI-совместимый API;
  - `anthropic`: Claude. Нужен `ANTHROPIC_API_KEY`. Используются `effort` и server-side fallback.

  Каждый адаптер сам ведёт историю в своём формате, разговор сбрасывается через 5 минут тишины.
- **Инструменты** (`bob/tools/`): `current_time`, `weather` (met.no), `calculator`.
- **Озвучка.** Модель пишет числа словами. Если цифры всё же проскочат, `bob/textnorm.py`
  озвучит их сам: «-1 °C» превратится в «минус один градус».

## Модель другого провайдера

В `config.local.yaml`:

```yaml
llm:
  provider: anthropic
  model: claude-opus-5-5
  effort: low
```

или любой OpenAI-совместимый API:

```yaml
llm:
  provider: openai_compat
  base_url: https://example.com/v1
  model: some-model
  api_key_env: MY_API_KEY
```

## Отключить устройство

В `server/data/devices.json` у устройства поставьте `"enabled": false`, например `{"tv": {"enabled": false}}`, и перезапустите сервер.
Такое устройство сервер не принимает: ни звука с него, ни плашек, ни голоса, ни команд ему. Чтобы вернуть, уберите ключ или поставьте `true`.
