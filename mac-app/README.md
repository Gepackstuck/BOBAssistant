# mac-app — Боб в строке меню Мака

Иконка в строке меню и плашка поверх всех окон, такая же, как на ТВ. Приложение только показывает
плашку и переключает голос. Микрофон и динамики Мака пока обслуживает Python-сервер (`server/`).

## Сборка и запуск

```sh
cd mac-app
./build.sh
open build/Bob.app
```

Нужны Command Line Tools со `swiftc` (Xcode не нужен). `build.sh` собирает `build/Bob.app`
и подписывает его ad hoc. Приложение без значка в Dock (`LSUIElement`).

Приложение подключается к серверу как устройство-экран `mac` по `ws://127.0.0.1:8765`.
Токен берёт из `~/BOBAssistant/server/secrets/token`. Переопределить можно переменными окружения
`BOB_SERVER`, `BOB_TOKEN`, `BOB_DEVICE`.

## Меню

- **Отвечать голосом** — галочка включает и выключает голосовой ответ для Мака. Настройка хранится на сервере.
  То же делает фраза «Боб, отвечай только текстом» и «Боб, отвечай голосом».
- **Светлая плашка** — галочка переключает тему плашки для Мака (тёмная по умолчанию). То же делает фраза «Боб, светлая тема».
- **Показать пример плашки** — тихая демонстрация всех фаз без сервера.
- **Выйти**.

## Проверка внешнего вида без записи экрана

```sh
build/Bob.app/Contents/MacOS/BobMac --snapshots /tmp/plates
```

Приложение само рисует плашку для каждой фазы в PNG и выходит.

## Вид

Цвета, темы, размеры и отступы лежат в `Sources/BobMac/Look.swift`, индикатор (орб, полоски) в `Indicator.swift`. Они подобраны так, чтобы плашка выглядела
как на ТВ (`tv-app/.../Overlay.java`). Описание в [docs/plate.md](../docs/plate.md).

## Запуск сервера из приложения

Приложение само запускает сервер Боба (`~/BOBAssistant/server/.venv/bin/bob`, запасной вариант `uv run bob`), пишет его вывод в `server/logs/server.out` (больше 5 МБ переименовывается в `.1`), перезапускает при падении и останавливает при выходе. Если порт 8765 уже занят сервером, запущенным вручную, приложение его не трогает. Меню: «Перезапустить Боба», «Показать лог», «Запускать при входе в систему» (при первом запуске включается само).

Разрешение на микрофон относится к приложению Боба. Приложение подписано без сертификата разработчика (`codesign --sign -`), поэтому после пересборки macOS может заново спросить разрешение.
