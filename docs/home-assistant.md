# Умный дом: Home Assistant

Боб управляет домом через Home Assistant (HA) по его REST API. Пока HA не настроен, инструменты дома в Бобе скрыты, а справка «что ты умеешь» про дом молчит.

## Что сделать (один раз)

1. **Запустить HA.** Проще всего контейнером в Docker Desktop (он на Маке уже стоит): `docker run -d --name homeassistant --restart unless-stopped -p 8123:8123 -v ~/homeassistant:/config ghcr.io/home-assistant/home-assistant:stable`. Открыть `http://localhost:8123`, создать пользователя.
2. **Подключить Яндекс и Сбер** (аккаунты и коды вводишь сам в интерфейсе HA, Бобу пароли не нужны):
   - Яндекс (Алиса, Станции, устройства Яндекса): интеграция `AlexxIT/YandexStation` через HACS.
   - Лампы Сбера: `altfoxie/ha-sberdevices` или `dzerik/ha-sberhome`.
3. **Дать Бобу доступ.** В HA: профиль → «Долгоживущие токены доступа» → создать. Положить в `server/secrets/home_assistant.json` (папка не в git):
   ```json
   {"url": "http://127.0.0.1:8123", "token": "ТОКЕН"}
   ```
4. Перезапустить Боба. Проверка: «Боб, какой свет включён?».

## Что умеет Боб

- «включи лампу красным», «выключи свет в спальне», «сделай лампу тёплой и поярче»: `home_control` (яркость в процентах, цвет по-русски, тёплый и холодный белый).
- «запусти сценарий вечер»: `home_scene` (сцены и скрипты HA).
- «какая температура дома», «выключен ли свет на кухне»: `home_status`.
- После команды для света на Маке слева внизу на шесть секунд появляется лампочка, которая светится настоящим цветом и яркостью лампы (Боб читает состояние из HA после команды, а не показывает то, что просили). Экран ради этого не включается. На ТВ пока нет.

Названия устройств Боб ищет по именам в HA («Лампа в спальне»), поэтому дай им понятные русские имена. Если названию подходит несколько устройств, Боб переспросит.

**Проверено на настоящем HA (2026.11.2, Яндекс через Yandex Station):** Боб видит лампы и читает их состояние; общий вопрос «какой свет включён» отвечается напрямую из данных HA, без модели, потому что модель домысливала комнаты. Управление светом голосом на настоящих лампах ещё не проверялось.
