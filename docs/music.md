# Музыка

Боб включает Яндекс Музыку на том устройстве, которое его услышало, без открытия приложения Яндекс Музыки.
Токен: [yandex-music-token.md](yandex-music-token.md).

## Что умеет

| Фраза | Что происходит |
|---|---|
| «Боб, включи Земфиру» | играют популярные треки исполнителя |
| «поставь песню Утекай» / «включи альбом …» / «включи плейлист …» | находит и включает |
| «включи Мою волну» | рекомендации Яндекса, очередь догружается сама |
| «что играет» | название и исполнитель |
| «пауза», «продолжи», «следующая», «предыдущая» | управление очередью |
| «громче», «тише» | громкость музыки на 15% (общая громкость ТВ не меняется) |
| «мне нравится» / «не нравится» | лайк / дизлайк, после дизлайка играет следующая |
| «выключи музыку» | остановка |
| «нет, другой» | если Боб включил не того исполнителя, играет следующий похожий вариант |

Команды управления разбираются кодом, пока музыка играет; просьбы включить музыку обрабатывает модель
через инструмент `play_music` (поиск по Яндекс Музыке, определение исполнителя или названия).

## Как устроено

- **Сервер** (`server/bob/music.py`): ищет, строит очередь, берёт прямую mp3-ссылку (до 192 кбит/с) и
  отправляет устройству команду `play`. Очередь и состояние хранит сервер, по одной на устройство.
- **ТВ** (`tv-app/.../MusicPlayer.java`): `MediaPlayer` в сервисе приложения. По окончании трека и каждые 2 с шлёт
  серверу событие; сервер включает следующий трек. Есть `MediaSession`, поэтому кнопки пульта «пауза» и «дальше» работают.
- **Мак** (`server/bob/macplayer.py`): `afplay` с временным файлом.
- **На время разговора** музыка ставится на паузу и после разговора продолжается.

## Важное про ТВ

- При «выключенном» с пульта ТВ прошивка TCL **ставит аудио на паузу**, если у приложения нет медиасеанса.
  С `MediaSession` и сервисом типа `mediaPlayback` музыка продолжает играть при спящем экране (проверено:
  позиция растёт при `mWakefulness=Asleep`).
- Звук идёт через общую громкость ТВ. Если ТВ без звука, музыки тоже не слышно.

## Проверка без звука

```sh
uv run bob music "Земфира"                         # поиск и ссылка, без воспроизведения
uv run bob music-play tv "Земфира" --volume 0      # играет с нулевой громкостью плеера
uv run bob music-control tv status                 # состояние и позиция
uv run bob music-control tv stop
```

Не вызывайте в автотестах `like` и `dislike`: они меняют аккаунт.

## Если Боб услышал имя не так

Whisper настроен на русский язык, поэтому латинские имена записывает по звучанию кириллицей: «madk1d» превращается в «маткит».
Против этого три вещи:

- **Подсказка из ваших исполнителей.** При запуске сервер берёт избранных исполнителей и самые частые в лайках и
  подсказывает их распознавателю (`server/data/taste.json`, обновляется раз в сутки).
- **Поиск по звучанию.** Имя ищется как услышано и в латинской транслитерации («маткит» → «matkit»), так находятся
  ближайшие варианты.
- **Запасные варианты.** Боб включает лучший результат и называет, что нашлось ещё. На «нет, другой» (также «не то»,
  «не тот») играет следующий исполнитель. Слово «Боб» повторять не нужно: после ответа есть окно уточнения.

На плашке виден распознанный запрос, так что ошибку слышно сразу.

## Ограничения

- «Что-нибудь спокойное» пока включает общую «Мою волну»: настроение и жанры (станции `mood:*`, `genre:*`) не подключены.
- Неофициальный API: Яндекс может его изменить.
- Лайк и дизлайк отправляются сразу, без подтверждения.
