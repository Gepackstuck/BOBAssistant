# Распознавание речи: что пробовали и что рассматриваем

Сравнение на семи фразах владельца (русская речь, английские имена исполнителей), 2026-11-18. Доля ошибочных слов, меньше — лучше.

| Движок | Среднее | Замечание |
|---|---|---|
| Whisper large-v3 | 29% | Выбран по умолчанию. Английские слова в обычной фразе пишет латиницей верно |
| Whisper turbo с подсказкой | 38% | Было раньше |
| GigaAM v3 rnnt | 39% | Английские имена пишет русскими буквами по звучанию («мэдкид вилиан», «вол лотос вэг») |
| GigaAM v3 e2e_rnnt | 43% | С пунктуацией, английские имена теряет |

Имена исполнителей ни одна модель не пишет верно: Whisper сам решает, как их писать («Мэтт Кит», «Lotus Factory»). Идея: сопоставлять
звуковую запись GigaAM с любимыми исполнителями, переведёнными в русское произношение (`pronounce.latin_to_speech`): «вол лотос вэг» даёт Whole Lotta Swag, сходство 0,74, следующий кандидат 0,38. Не реализовано.

GigaAM у нас запускался из Hugging Face (`ai-sage/GigaAM-v3`, ревизии `e2e_rnnt` и `rnnt`) с `transformers==4.57.1`: скачивание с сервера Сбера не проходило из-за просроченного сертификата.

## Aqua Voice (aquavoice.com)

Приложение для диктовки (Mac, Windows, iPhone, Android-телефоны) с облачным распознаванием, есть API: `POST /v1/audio/transcriptions`, совместимое с OpenAI SDK
(модель `avalon-v1.5`, $0,39 за час звука), русский поддерживается. Аудио уходит на их серверы. Личный словарь доступен на платном тарифе, на Android TV приложения нет.
Заявленные ими 97,4% на технических терминах получены на их собственном английском наборе и для нас ничего не доказывают. Не проверялось.
