## 0. Разведка телевизора ✅

Что умеет ТВ и что из этого следует: [recon-tv.md](recon-tv.md).

## 1. «Мозг» на Маке 🔨

- [x] Кодовые слова («Боб», «Миньон», «Подручный», «Окей, Сбер») с проверкой по тексту
- [x] Распознавание речи, ответ модели с инструментами, голос (по слову разный)
- [x] Модель подключается адаптером: Ollama, любой OpenAI-совместимый API, Claude
- [x] Инструменты: время, погода в любом городе, калькулятор
- [ ] Обученные модели кодовых слов (openWakeWord): синтетических данных мало, нужны записи голосов
- [x] Имена исполнителей по звучанию через GigaAM (запасной путь для музыки, когда обычный поиск не нашёл): отдельный помощник `server/helpers/gigaam`, ставится `./setup.sh`

## 2. Приложение для ТВ 🔨

- [x] Сервер запускает приложение Боба в строке меню: поднимает его при старте, перезапускает при падении (паузы 3, 6, 9… секунд), останавливает при выходе; пункты меню «Перезапустить Боба», «Показать лог» (Console) и «Запускать при входе в систему»; Терминал не нужен
- [ ] Перенос музыки с устройства на устройство

## 3. Качество диалога 🔨

- [x] Память: «запомни», «забудь»
- [x] Поиск в интернете для свежих фактов
- [x] Справки о людях, местах и понятиях из Википедии («кто такой», «сколько лет», «что такое»): инструмент `encyclopedia`, возраст считает сам инструмент; модель обязана искать, а не отвечать по памяти
- [ ] Уточнение неоднозначных имён («Лолита»: певица или роман) и ответ с обложкой-карточкой на плашке
- [x] Уточнения без кодового слова, без лишних встречных вопросов
- [x] Голос и тема плашки настраиваются отдельно для каждого устройства
- [x] Громкость голоса Боба отдельная для каждого устройства: меню на Маке и голосом («говори тише», «громкость голоса пятьдесят процентов»)
- [x] Разговор можно закончить: «спасибо, хватит», «отбой» закрывают плашку без ответа; не больше трёх уточнений подряд и 90 секунд на разговор
- [x] Латинские имена и слова произносятся по-русски («madk1d» → «мэдкид»)
- [x] Короткий ответ голосом и подробный на плашке: модель пишет голосовую часть, затем `|||` и подробности, которые видны только на плашке
- [x] «Подробнее» (всё вслух, до шести предложений) и «короче»
- [x] Набор эталонных фраз: `docs/reference-phrases.txt`, прогон `uv run bob eval --out результат.md` без звука и без музыки

## 4. Яндекс Музыка 🔨

- [x] Исполнитель, песня, альбом, плейлист, «Моя волна», очередь ([музыка](music.md))
- [x] Проверка совпадения: трек или альбом не играет, если не совпал с названным; ошибка поиска не превращается в выдумку модели
- [x] Пауза, дальше, назад, громкость, лайк, «что играет»
- [x] ТВ играет и при выключенном экране
- [x] Похожие имена: запасные варианты и «нет, другой»
- [ ] Проверка голосом
- [x] Настроение, занятие, эпоха и жанр («что-нибудь спокойное», «для работы», «девяностые», «джаз») через станции Яндекса
- [x] Карточка «сейчас играет» с обложкой на Маке: висит, пока играет музыка (пауза показывается значком); на ТВ ещё не сделана

## 5. Умный дом 🔨

Home Assistant на Маке, лампы Сбера напрямую, остальное через Яндекс. Код Боба готов и проверен на макете HA; ждёт запуска настоящего HA и токена: [инструкция](home-assistant.md).

- [x] Устройства, сценарии, датчики голосом (код; на настоящем HA не проверено)
- [x] **Лампа на плашке** (Мак; на ТВ нет). Команда «включи лампу красным» показывает на плашке лампочку, которая загорается тем цветом
  и той яркостью, с какими включена. «Выключи» гасит её. Несколько ламп: ряд лампочек с названиями
- [x] **Плашка показывает настоящее состояние лампы** (читает после команды; обновление по изменению снаружи не сделано), а не только команду: цвет и яркость берутся из Home Assistant
  после подтверждения. Если лампа не ответила, это видно. Пока плашка на экране, изменения (выключателем, из приложения) обновляют её сами
- [ ] Экран ТВ ради лампы не включается: лампочка показывается, только если экран уже горит
- [ ] События дома на плашке (звонок, протечка)

## 6. Управление ТВ 🔨

Команды исполняет само приложение ТВ штатными средствами Android (без `adb`, поэтому отладку по Wi-Fi в конце можно закрыть).

- [x] Громкость ТВ (громче и тише по 10%, «намного» по 20%, точный уровень, выключить и включить звук, узнать уровень), запуск приложений по названию («открой ютуб», «запусти кинопоиск»), «домой»; можно и с Мака («на телевизоре»)
- [ ] Источники HDMI и «назад» (нужны отдельные пути: ввод ТВ и служба доступности)
- [ ] Кинопоиск: пауза, перемотка на позицию и на N минут
- [ ] Таймер выключения

## 6.5. Справка «что ты умеешь» ⬜

«Боб, что ты умеешь?» даёт примерный список команд. Для ТВ и Мака списки разные.

- [x] Короткий ответ голосом и подробный список на плашке
- [x] Уточнение по группе: «что умеешь с музыкой?»
- [x] Список собирается из реестра возможностей: модуль сам описывает свои команды и на каких устройствах они работают
- [x] Неподключённые модули в справке не показываются

## 7. Вызов из сна 🔨

ТВ, выключенный с пульта, продолжает работать и остаётся в сети, поэтому Raspberry Pi не нужен.

- [x] Приложение слушает во сне, сеть ТВ в режиме ожидания открыта
- [ ] Проверка: выключенный ТВ включается голосом

## 8. Повседневное 🔨

- [x] Таймеры, напоминания, будильники (в том числе каждый день), список покупок: хранятся в `server/data/planner.db`, переживают перезапуск, срабатывают на устройстве, где поставлены (если оно не подключено, то на Маке), с сигналом и голосом
- [x] Утренняя сводка: «доброе утро» и «что на сегодня» (дата, погода дома, планы, список покупок)
- [ ] Календарь (нужен доступ: Яндекс Календарь по CalDAV и пароль приложения)
- [ ] Telegram-бот (нужен токен бота от @BotFather)

## 10. Боб вместо Google Assistant ⬜

«Ok Google» не нужен: Боб становится системным ассистентом ТВ.

- [ ] `VoiceInteractionService` и роль ассистента вместо Google
- [ ] Кнопка микрофона на пульте вызывает Боба
- [ ] Режим Low Power Standby можно вернуть включённым

## 11. Современный вид лаунчера ТВ 🔨

Лаунчер ТВ (`tvclean/launcher`, ветка `my-tv`) перерисовать в стиле новой плашки ([плашка](plate.md)).

- [x] Тот же язык оформления: мягкие карточки без рамок, акцентный орб, крупная типографика; только тёмная тема (светлую решили не делать)
- [x] Первый проход на ТВ: верхняя плашка (орб, крупное время, без рамки), подложка ряда приложений без рамки и круглее плитки, боковая панель (без рамки, полоса памяти в цветах орба), часовая заставка (плотные часы, орб); не сделано: погода отдельно, подсветка выбранной плитки в цвета орба, заставка с фото (`MonkeyDream`) уже в стеклянном стиле
- [x] **Старый вид остаётся** и переключается строкой «Новый вид» внизу боковой панели под диспетчером задач; по умолчанию включён новый (`ui_style` в `config.xml` или в теме)

## Правила

- Сервер на Маке, наружу не открывается, устройства входят по токену.
- Цель по задержке: 2 секунды от конца фразы до начала ответа.
- В репозиторий не попадают IP, MAC, серийные номера, токены и названия Wi-Fi.
- README и этот план всегда актуальны и со скриншотами.
