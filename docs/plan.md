## 0. Разведка телевизора ✅

Что умеет ТВ и что из этого следует: [recon-tv.md](recon-tv.md).

## 1. «Мозг» на Маке 🔨

- [x] Кодовые слова («Боб», «Миньон», «Подручный», «Окей, Сбер») с проверкой по тексту
- [x] Распознавание речи, ответ модели с инструментами, голос (по слову разный)
- [x] Модель подключается адаптером: Ollama, любой OpenAI-совместимый API, Claude
- [x] Инструменты: время, погода в любом городе, калькулятор
- [ ] Обученные модели кодовых слов (openWakeWord): синтетических данных мало, нужны записи голосов
- [ ] Более точное распознавание (GigaAM)

## 2. Приложение для ТВ 🔨

<img src="img/plate-dark-answer.png" width="420">

- [x] Микрофон ТВ с усилением, эхоподавление
- [x] Плашка поверх любых окон: запрос по мере речи, ответ, уточнение, тёмная и светлая тема ([плашка](plate.md))
- [ ] Новый вид плашки установлен на ТВ и проверен (сборка готова, ждёт ADB)
- [x] Фильм на паузе на время разговора, экран ТВ включается сам
- [ ] Автозапуск после перезагрузки ТВ (исправление собрано, проверить)
- [ ] Проверка голосом с дивана

## 2.5. Мак как устройство 🔨

<img src="img/plate-light-answer.png" width="420">

- [x] Приложение в строке меню, такая же плашка, переключатели голоса и темы ([mac-app](../mac-app))
- [ ] Микрофон и динамик Мака внутри приложения, без терминала
- [ ] Перенос музыки с устройства на устройство

## 3. Качество диалога 🔨

- [x] Память: «запомни», «забудь»
- [x] Поиск в интернете для свежих фактов
- [x] Уточнения без кодового слова, без лишних встречных вопросов
- [x] Голос и тема плашки настраиваются отдельно для каждого устройства
- [x] Разговор можно закончить: «спасибо, хватит», «отбой» закрывают плашку без ответа; не больше трёх уточнений подряд и 90 секунд на разговор
- [x] Латинские имена и слова произносятся по-русски («madk1d» → «мэдкид»)
- [ ] Короткий ответ голосом и подробный на плашке
- [ ] «Подробнее» и «короче»
- [ ] Набор эталонных фраз для сравнения моделей (последние фразы Мака можно сохранять: `debug.keep_utterances`)

## 4. Яндекс Музыка 🔨

- [x] Исполнитель, песня, альбом, плейлист, «Моя волна», очередь ([музыка](music.md))
- [x] Проверка совпадения: трек или альбом не играет, если не совпал с названным; ошибка поиска не превращается в выдумку модели
- [x] Пауза, дальше, назад, громкость, лайк, «что играет»
- [x] ТВ играет и при выключенном экране
- [x] Похожие имена: запасные варианты и «нет, другой»
- [ ] Проверка голосом
- [ ] Настроение и жанры («что-нибудь спокойное»)
- [ ] Плашка «сейчас играет» с обложкой

## 5. Умный дом ⬜

Home Assistant на Маке, лампы Сбера напрямую, остальное через Яндекс.

- [ ] Устройства, сценарии, датчики голосом
- [ ] **Лампа на плашке.** Команда «включи лампу красным» показывает на плашке лампочку, которая загорается тем цветом
  и той яркостью, с какими включена. «Выключи» гасит её. Несколько ламп: ряд лампочек с названиями
- [ ] **Плашка показывает настоящее состояние лампы**, а не только команду: цвет и яркость берутся из Home Assistant
  после подтверждения. Если лампа не ответила, это видно. Пока плашка на экране, изменения (выключателем, из приложения) обновляют её сами
- [ ] Экран ТВ ради лампы не включается: лампочка показывается, только если экран уже горит
- [ ] События дома на плашке (звонок, протечка)

## 6. Управление ТВ ⬜

- [ ] Громкость, источники HDMI, запуск приложений, «домой» и «назад»
- [ ] Кинопоиск: пауза, перемотка на позицию и на N минут
- [ ] Таймер выключения

## 6.5. Справка «что ты умеешь» ⬜

«Боб, что ты умеешь?» даёт примерный список команд. Для ТВ и Мака списки разные.

- [ ] Короткий ответ голосом и подробный список на плашке
- [ ] Уточнение по группе: «что умеешь с музыкой?»
- [ ] Список собирается из реестра возможностей: модуль сам описывает свои команды и на каких устройствах они работают
- [ ] Неподключённые модули в справке не показываются

## 7. Вызов из сна 🔨

ТВ, выключенный с пульта, продолжает работать и остаётся в сети, поэтому Raspberry Pi не нужен.

- [x] Приложение слушает во сне, сеть ТВ в режиме ожидания открыта
- [ ] Проверка: выключенный ТВ включается голосом

## 8. Повседневное ⬜

- [ ] Таймеры, напоминания, будильник, список покупок
- [ ] Утренняя сводка, календарь, Telegram-бот

## 10. Боб вместо Google Assistant ⬜

«Ok Google» не нужен: Боб становится системным ассистентом ТВ.

- [ ] `VoiceInteractionService` и роль ассистента вместо Google
- [ ] Кнопка микрофона на пульте вызывает Боба
- [ ] Режим Low Power Standby можно вернуть включённым

## 11. Современный вид лаунчера ТВ ⬜

Лаунчер ТВ (`tvclean/launcher`, ветка `my-tv`) перерисовать в стиле новой плашки ([плашка](plate.md)).

- [ ] Тот же язык оформления: мягкие карточки без рамок, акцентный орб, крупная типографика, тёмная и светлая темы
- [ ] Часы, погода, боковая панель и заставка в новом стиле
- [ ] **Старый вид остаётся** и переключается настройкой, чтобы можно было вернуться в любой момент

## Правила

- Сервер на Маке, наружу не открывается, устройства входят по токену.
- Цель по задержке: 2 секунды от конца фразы до начала ответа.
- В репозиторий не попадают IP, MAC, серийные номера, токены и названия Wi-Fi.
- README и этот план всегда актуальны и со скриншотами.
